stdio -> mais importante, IO, 

stdlib -> alocação dinâmica, conversão de tipos, controle de processos, etc. Controlar a memória, alocar e liberar memória, converter tipos de dados, controlar processos, etc.


string -> manipulação de strings, funções para lidar com strings, como copiar, concatenar, comparar, etc. 


math -> funções matemáticas, como trigonometria, exponenciais, logaritmos, etc. Fornece funções para realizar operações matemáticas avançadas, como trigonometria, exponenciais, logaritmos, etc.


time -> manipulação de tempo, funções para lidar com data e hora, como obter a hora atual, formatar datas, etc. Fornece funções para lidar com data e hora, como obter a hora atual, formatar datas, etc.



ctype -> manipulação de tipos de dados, funções para lidar com tipos de dados, como verificar o tipo de um valor, converter tipos, etc. Fornece funções para lidar com tipos de dados, como verificar o tipo de um valor, converter tipos, etc.


stdbool -> manipulação de booleanos, funções para lidar com valores booleanos, como verdadeiro e falso. Fornece suporte para o tipo de dados booleano, permitindo o uso de valores verdadeiro e falso em C.
